# Catbots brand

**See the logic.**

Catbots turns trading ideas into rules people can inspect. The brand should make that clarity visible: a curious Cat-C symbol, confident cobalt, warm butter, and direct language.

## Use the current identity

The approved identity is [Cat-C / Direction 02](2026-09-11/direction-02/README.md). The earlier orange cat-and-nodes proposal is archived in `2026-09-11/`; it is not the current brand.

| Element | Convention |
| --- | --- |
| Symbol | Curled cat forming a C, with two ears and two eye cutouts |
| Name | **Catbots** in prose; **catbots** in the visual wordmark |
| Primary line | **See the logic.** |
| Supporting line | **One idea. Every rule visible.** |
| Personality | Curious, observant, clear, technically capable |
| Cobalt | `#2448FF` — brand emphasis and primary actions |
| Butter | `#F4F0C8` — warm surfaces and reversed artwork |
| Paper | `#FAFAF5` — content surfaces |
| Ink | `#151515` — text |

Keep risk, loss, success, and node-category colors distinct from the brand palette. Explain fees, approvals, and execution scope literally. Never imply guaranteed returns or autonomous capabilities the current release does not provide.
